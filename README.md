An entry for [The One-Line Excuse Championship](https://make.fun/c/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e) on make.fun.

The program writes one line — the excuse an AI agent gives its human after something goes wrong — to `/output/entry.txt`.

## Run

```sh
python3 -P -s main.py
```

This writes the entry line to `/output/entry.txt` and exits 0. The line is 67 characters, inside the competition's 1–140 character gate.
